# MegaTXT II — Reference UI Lock

The Storybook visual design in this project is intentionally locked to the supplied mobile reference image.

- Do not regenerate, redraw, replace, or "improve" the pagoda, mountains, sakura, or sleeping-cat artwork.
- The Storybook artwork files under `src/assets/images/reference_exact/` are crops taken directly from the supplied reference image.
- Do not substitute AI-generated artwork for these files.
- Do not change the translation engine, API scheduling, batching, chunking, pause/resume, Telegram, authentication, or export logic as part of visual work.
- If a build/runtime problem occurs, fix only the actual build/runtime problem and leave the visual implementation intact.
